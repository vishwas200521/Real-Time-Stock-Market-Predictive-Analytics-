# 📈 Real-Time Stock Market Predictive Analytics Dashboard

An interactive stock market analytics dashboard built using **Python, Pandas, Plotly, Streamlit, and Facebook Prophet**. The project analyzes historical stock data, visualizes key market trends, and forecasts future stock prices using time-series forecasting.

---

## 🚀 Features

- 📊 Interactive dashboard built with Streamlit
- 📈 Historical stock price visualization
- 📉 Candlestick chart analysis
- 📊 Trading volume analysis
- 📈 Moving Average (MA20 & MA50) visualization
- 📉 Daily Returns analysis
- 📊 Rolling Volatility visualization
- 🤖 30-Day Stock Price Forecast using Facebook Prophet
- 📋 Forecast summary and prediction table
- 📥 Download forecast results as CSV

---

## 📌 Workflow

1. Collect historical stock market data
2. Clean and preprocess the dataset using Pandas
3. Perform feature engineering
4. Conduct exploratory data analysis (EDA)
5. Build an interactive Streamlit dashboard
6. Generate 30-day stock price forecasts using Prophet
7. Visualize insights with Plotly

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Stock-Predictive-Dashboard.git
```

### Navigate to the project folder

```bash
cd Stock-Predictive-Dashboard
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the dashboard

```bash
streamlit run app/dashboard.py
```
